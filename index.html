Database on cholesterol binding in class A GPCRs

David Sotillo Núñez 1, Giovanni Bottegoni 1
1 Università degli Studi di Urbino Carlo Bo - Dipartimento di Scienze Biomolecolari. Campus Scientifico Enrico Mattei, Via Ca' Le Suore, 2/4, 61029 Urbino, ITALY.

This is a comprehensive platform on cholesterol binding data in class A G protein-coupled receptors obtained through the analysis of coarse-grained molecular dynamics (CG-MD) using the Martini 3 force field 1. We include two different approaches for data visualization: Inspection of the data on individual structures and visualization of the aggregated data based on family groupings. Note that only those groups and sub-groups containing 4 or more structures are eligible for aggregated visualization, the rest are greyed out in the menu. The pockets displayed here were detected using the NanoShaper software 2, available online in their NanoShaper web platform. The protein residues are identified using their own residue ID in the original PDB structure for the individual systems. For both, individual systems and aggregated data we provide the Ballesteros-Weinstein generic residue annotation for class A GPCRs. It uses the format H.NN, where H states the helix where the residue is located at and NN how far a residue is from the most conserved residue in that helix (e.g. 4.50 is the most conserved residue in helix 4) 3. Results on individual structures can be accessed by clicking on the desired PDB id in the interactive tree below or by navigating the menu. Available aggregated results can be reached by clicking on the relevant groups on the corresponding menu below (Unavaiable entries with not enough data are greyed out).
